# Le Repaire : dépôt des packs

Fichiers publiés automatiquement pour le launcher Le Repaire : la liste des packs, leurs manifestes et nos propres mods.
Les mods des autres auteurs n'y sont pas : le launcher les télécharge depuis CurseForge et Modrinth.

Projet entre amis, non officiel, sans lien avec Mojang ou Microsoft.
